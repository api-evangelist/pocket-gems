## Important: there is no Pocket Gems API

Pocket Gems publishes **no public API, no developer portal, no API reference, and no
machine-readable specification** (OpenAPI, AsyncAPI, GraphQL SDL, MCP manifest, or A2A
agent card). Contract discovery on 2026-08-05 probed every public host — `pocketgems.com`,
`episodeinteractive.com`, `home.episodeinteractive.com`, `wardragons.com` — for
`/openapi.json`, `/api-docs`, `/.well-known/*` discovery documents, and both A2A agent-card
paths, and DNS-resolved `api.`, `developer.`, `developers.`, `docs.`, `dev.`, `partner.`,
`graphql.`, `portal.` and `status.` subdomains. Only `docs.pocketgems.com` resolves, and it
redirects to an Okta/Google Workspace SSO login for internal Google Drive — it is not
developer documentation.

Do not infer, guess, or synthesize a Pocket Gems API endpoint. There is not one to call.

  Writer's Portal, not through an HTTP API.
- [Episode XOXO](https://www.pocketgems.com/episode-xoxo/): companion interactive story app.

- Mantis Engine: proprietary mobile-first game technology platform (internal; not licensed
  or documented publicly).

## Open source (the actual public developer surface)

Pocket Gems maintains a GitHub organization and publishes four first-party Apache-2.0
Node.js libraries — the internal "Todea" service stack. These are infrastructure libraries,
**not client SDKs for a Pocket Gems API**.

- [github.com/pocketgems](https://github.com/pocketgems): 65 public repositories, 15 of them
  first-party (the rest are forks of upstream open source).
- [@pocketgems/dynamodb](https://www.npmjs.com/package/@pocketgems/dynamodb): transactional,
  schemaful SDK for AWS DynamoDB with query and index support.
- [@pocketgems/app](https://www.npmjs.com/package/@pocketgems/app): Todea App Library, the
  service framework behind Pocket Gems HTTP services.
- [@pocketgems/schema](https://www.npmjs.com/package/@pocketgems/schema): fluent JSON Schema
  and AWS C2J shape-schema construction.
- [@pocketgems/unit-test](https://www.npmjs.com/package/@pocketgems/unit-test): Jest +
  Supertest wrapper.
